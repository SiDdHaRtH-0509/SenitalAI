# Lead 4 — Support / QA / Documentation / Demo

## Responsibilities
Support the team without owning a critical runtime dependency. Focus on testability, reproducibility, documentation, sample-data hygiene and the final demo.

## Assigned files
- This Lead folder.
- QA run sheets, demo evidence and approved support docs.
- Any isolated fixture/script only with Overall Lead approval.

## Dependencies
- Working branches from core owners.
- Shared contracts and environment instructions.
- Authorized sample video and actual IBM deployment status.

## Deliverables
- Completed QA report.
- Reproducible setup notes.
- Blocker log and task board updates.
- Demo script and backup recording/screenshots.
- PR on `lead-4/support`.

## Done when
The team can reproduce the demo, test results are evidence-backed, and the presentation does not overstate system capabilities.
