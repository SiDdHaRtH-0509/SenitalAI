# Lead Workspaces

Each lead owns one workstream. Read the corresponding `PROMPT.md`, `CHECKLIST.md`, `NEXT_TASK_PROMPT.md`, and `README.md` before editing code. Shared contracts in the repository root take precedence over assumptions made by any coding assistant.

- Lead 1: Frontend dashboard
- Lead 2: Computer vision and observable event generation
- Lead 3: IBM LinuxONE environment and deployment
- Lead 4: QA, documentation, and demo support

The Overall Project Lead coordinates the team and owns backend/API integration and merge approvals.
